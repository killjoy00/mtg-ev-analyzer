New Daily generation deletes the existing schedule when its corpus version differs. Completion writes guest scores to the ranked table. All result sharing creates a challenge. ## Staged practice and capabilities

New practice generation requires a valid managed account session. Every free account has `account` and `unlimited_regular_practice`; durable database grants add `unlimited_cube_practice` and `custom_corpus`. Provider adapters verify their own events and resolve an existing account before writing generic grants. No payment provider is connected or advertised. Grant expiration/revocation applies to new runs; existing sessions remain readable and finishable.

Shared practice retains a stable stored identity and the exact decisions. Recipients need the corresponding practice capability. A shared replay has no rerolls; copying its result reuses the original link, and that link lists completed scores on those identical decisions. Ordinary random practice keeps rerolls. Custom practice balances the eight decisions across selected Live regular sets and permits pack rerolls only, preserving the set composition.

The homepage exposes applicable practice capabilities only after both Dailies are complete. The Corpus dashboard and final backend release remain separate pending stages.
