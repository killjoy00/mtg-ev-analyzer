## What is implemented

The initial PR contains 44 files. Key pieces:

- `model-versions.json` and `scripts/model_training.py` distinguish historical
  v4 defaults from v5 all-qualified/null-cap policy. V5 rejects positive or
  negative caps; omitted/zero means all qualified. Manifest checks require an
  explicit v5 model, all-qualified mode, null cap, and trained=qualified count.
- Regular, full-trophy, legacy, Cube, replay and path build paths propagate the
  policy/version. Historical v4 defaults remain. The path architecture retains
  its own `strong-player-counterfactual-path-v3` identity and records the v5
  context parent and exclusions separately.
- `draft-run.mjs` deliberately still serves v8 in this implementation PR.
  V9 constants/validation reject old or missing model identities. The generated
  release will switch the serving constant after the full build passes.
- `worker/draft-run-season.mjs` implements the reversible v9-only public
  leaderboard filter; historical rows and personal history remain. Fixed old
  Dailies completed after transition remain old and do not enter v5 standings.
- V5 Traditional component identities are
  `traditional-premier-v5-phase2-v1` and `traditional-cube-p2p7-v5-v1`.
  Allowlist, additive migration `0048_uncapped_v5_components.sql`, backend
  migration gate, and loader support are implemented. New loaders validate
  exact source membership, ledger bytes, source hashes, inherited windows,
  unchanged quality thresholds, Premier input identity, and actual v5 parity.
  Historical v3/v4 handling remains.
- `verify-corpus-load.mjs` distinguishes the baseline replay-derived inventory
  from the complete first-class trophy snapshot; both stage, only the active
  snapshot serves. Baseline rows cannot substitute for full snapshot coverage.
- `scripts/v5_rebuild.py`, `v5_traditional.py`, `v5_sources.py`, and
  `v5_rebuild_qa.py` implement the frozen-source, checkpointed rebuild and QA.
  Existing builder/replay algorithms are reused. New replay source proof is
  extracted from actual pinned source bytes, not relabeled from the old sample.

  model map rather than the current serving corpus. An old literal expectation
